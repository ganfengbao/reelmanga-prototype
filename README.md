# 一键漫剧 · 网站高保真原型

> 产品名：**漫剧工场 REELMANGA** ——「一句话，一键生成爆款漫剧」
> 参考市面产品：抖音/快手短剧、番茄小说、ReelShort、可灵 / 即梦 / Runway 等 AI 视频工具、快看漫画。

## 如何查看原型

直接双击打开 `index.html`（或拖入浏览器）即可，无需任何依赖、无需联网。
它是一个单文件高保真交互原型，包含 5 个页面视图 + 1 个播放器弹窗，均可用鼠标点击交互。

## 页面结构

| 视图 | 入口 | 内容 |
|------|------|------|
| 首页 | 顶部「首页」 | Hero 主视觉 + 魔法输入框、悬浮预览卡、数据条、六大特性、风格引擎、三步流程、爆款作品、用户评价、CTA |
| 创作台 | 顶部「创作台」/「开始创作」 | 左侧配置面板（脚本/风格/画幅/集数/配音/BGM）+ 右侧 9:16 实时预览与分镜；点击「一键生成」会模拟完整生成进度动画 |
| 作品库 | 顶部「作品库」 | 题材筛选 Tab + 搜索 + 竖屏作品瀑布流（悬停显示播放按钮） |
| 定价 | 顶部「定价」 | 免费 / Pro / Studio 三档方案，含月付·年付切换 |
| 播放器 | 点击任意作品卡片 | 9:16 播放弹窗，含进度条、点赞/收藏/分享/下载、播放暂停 |

## 可交互点

- 顶部导航与页脚链接：切换视图
- 首页魔法输入框：点击「一键生成」或题材标签 → 跳转创作台并自动开始生成动画
- 创作台：风格/画幅/集数/配音/BGM 均可点选；「一键生成漫剧」触发分步进度 → 完成后出现「播放成片 / 下载 / 发布」
- 作品库：Tab 筛选、卡片悬停、点击卡片打开播放器
- 播放器：播放/暂停（时间会走）、关闭
- 定价：年付/月付切换

## 设计系统

- **配色**：深色底 `#0a0a12` + 紫→品红→玫瑰渐变（AI 创意工具的通用心智），点缀青/琥珀作为状态色
- **字体**：中文系统栈（PingFang SC / 微软雅黑 / 思源黑体），英文数字用 Sora/Barlow 做层级
- **质感**：玻璃拟态导航与卡片、径向网格背景、弥散光斑、渐入滚动动画、光扫 logo
- **内容形态**：全站以 **9:16 竖屏视频卡** 为核心视觉，贴合「漫剧」的短视频分发心智
- **插画**：角色剪影用内联 SVG 程序化生成，题材对应不同渐变与剪影（女/男/情侣/持剑），无需外部图片资源
